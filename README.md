# GRAV-BOT

Juego de pixel art en blanco y negro: un robot corre sin parar y cada toque invierte la gravedad entre piso y techo.

**Jugar:** https://jjzamo.github.io/grav-bot/

## Controles
- Toque / click / Space: invertir gravedad
- P o Esc: pausa

## iPhone
Abrir el link en Safari → Compartir → "Agregar a pantalla de inicio" para jugar en pantalla completa como app. Jugar en horizontal.
